# 变更日志

## [1.0.0] - 2026-07-09

### 新增功能

- 实现了完整的天枢系统架构，包括七个核心层：
  - 意图解析层
  - 语义任务图层
  - 异构角色层
  - 认知拓扑路由层
  - 分层任务记忆层
  - 端云自适应调度层
  - 观测评测层

- 实现了动态稀疏拓扑路由算法，显著降低了多智能体系统的通信复杂度

- 实现了最小上下文检索算法，有效减少了长程任务中的 token 冗余

- 实现了受影响子图重算算法，提高了故障恢复的效率

- 实现了分层任务记忆系统，包括短期工作记忆、中期情景缓存和长期知识沉淀

- 实现了端云自适应调度器，能够根据任务属性动态选择计算资源

- 实现了故障注入与自恢复机制，支持需求变更、节点失败、工具失败、记忆缺失和资源降级等多种故障类型

- 实现了低熵结构化通信协议，规范了智能体之间的通信格式

- 实现了基于 SQLite 的存储系统，支持任务图、消息、事实、产物、指标和故障等数据的持久化

- 实现了命令行接口，支持任务运行、评估基准、报告生成、仪表板启动和故障注入等功能

- 实现了 Web 仪表板，提供可视化的任务执行状态监控

- 实现了多种智能体角色，包括规划者、研究员、编码员、验证员、审查员、记忆管理员、资源经纪人和恢复代理

- 实现了完整的评估体系，包括软件工程、研究报告和故障注入三个基准测试

### 改进

- 优化了任务图的表示和操作，支持动态更新和状态转换

- 改进了角色注册和管理机制，支持动态添加和配置智能体角色

- 优化了资源调度算法，提高了资源利用效率

- 改进了故障检测和分析机制，提高了系统的鲁棒性

- 改进了通信协议，减少了通信开销

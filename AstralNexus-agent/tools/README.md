# AstralNexus 工具集

## 概述

AstralNexus 工具集为系统中的智能体提供了各种功能工具，包括文件操作、网络请求、代码执行等。

## 工具列表

### 内置工具

1. **template** - 模板工具，可作为新工具的起点

## 自定义工具

要创建自定义工具，请按照以下步骤操作：

1. 在 `tools/` 目录下创建新的 Python 文件
2. 实现工具函数，确保函数接受一个字典参数并返回一个字典结果
3. 在 `executor.py` 中注册工具

示例：
```python
def my_custom_tool(params):
    # 工具逻辑
    return {
        "status": "success",
        "data": "result"
    }
```

## 工具接口规范

所有工具必须遵循以下接口规范：

- **输入**：一个字典参数，包含工具所需的所有参数
- **输出**：一个字典结果，包含状态和数据
- **错误处理**：工具应在内部处理错误并返回适当的错误信息

## 工具执行器

`ToolExecutor` 类负责管理和执行所有工具。它提供了以下功能：

- 工具注册
- 工具执行
- 工具列表查询
- 执行跟踪记录

## 开发新工具

开发新工具时，请遵循以下最佳实践：

1. 保持工具功能单一
2. 提供清晰的文档字符串
3. 处理可能的异常情况
4. 返回一致的结果格式
5. 记录工具的使用情况

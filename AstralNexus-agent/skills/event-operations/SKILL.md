# Event Operations

Create an owner-assigned work breakdown with dates, dependencies, budget and
acceptance checks. Cover venue, agenda, speakers, registration, hotel,
transport, catering, production, media, staffing, safety and medical plans.
During the event, ingest status updates, detect deviations and issue reversible
adjustments; finish with attendance, budget, incident and outcome review.

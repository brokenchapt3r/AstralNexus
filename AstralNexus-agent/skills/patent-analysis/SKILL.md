# Patent Analysis

Separate technical disclosure, essential and optional features, prior-art
evidence, distinguishing combinations, technical effects, claims, description
support and implementation examples. Check every claim against the
description, unify terms, identify contradictions and mark legal conclusions
as review items rather than professional legal advice.

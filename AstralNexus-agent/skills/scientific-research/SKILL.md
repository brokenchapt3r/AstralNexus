# Scientific Research

Define search scope and screening criteria, collect papers, patents, datasets
and code, preserve evidence references, compare contradictions, generate
testable hypotheses, and run a baseline or minimal experiment when inputs and
resources permit. Report datasets, baselines, metrics, failure criteria and
reproducibility evidence; never present a plan as a completed experiment.

# Backend Testing

Build an evidence-backed test pyramid: unit tests for rules, integration tests
for API and database flows, authentication and authorization cases, failure
paths, and deployment smoke tests. Keep fixtures isolated, test transactions
and rollback explicitly, and report commands, return codes, logs and coverage.

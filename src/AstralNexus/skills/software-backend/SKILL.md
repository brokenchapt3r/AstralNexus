# Backend Engineering

Define validated API boundaries, data invariants, authorization rules,
idempotency, transactions, timeouts, structured errors and observability
before implementation. Produce runnable code and tests, inspect migrations,
exercise failure paths, and verify deployment and rollback rather than
returning architecture-only prose.

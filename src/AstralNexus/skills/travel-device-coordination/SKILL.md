# Travel and Device Coordination

Extract meeting facts from authorized calendars, mail and files. Classify
sensitivity before choosing local, edge or cloud processing. Produce itinerary,
contacts, transport, lodging, carry list, device readiness, offline package,
sync plan and risks. Never move sensitive files or access private systems
without explicit permission and an auditable destination.
